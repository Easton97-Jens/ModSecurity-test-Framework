## Acceptance criteria

Preserve the exact 022 and 077 permission decisions and status 77 for rejected input. Keep the valid workflow expansion outside the exception assertion and reject its manipulated SHA. Require current-source regression results and a fresh hosted readback before claiming finding or parser closure.

## Alternatives considered

Removing permission checks, broadening accepted modes, suppressing rules, reducing analysis scope or weakening the Gate would invalidate the contract. Moving multiple potentially failing calls into the expected-exception block would weaken the negative control.

## Implementation decision

Use validated octal-digit patterns for both permission masks, with explicit no-op default branches. The 022 mask rejects write bits in group/other digits; the 077 mask rejects any group/other access. Calculate mutation inputs before the assertion. Keep only `expand_workflow_source` inside the expected `WorkflowSourceError` block, after a separate valid expansion.


The first native Python 3.15.2 quick-check failed two methods that exercise the same writerless-FIFO control. Measured spawn/import startup took 2.49–2.62 seconds, exceeding a two-second ready clock started before bootstrap. The reader itself rejected the FIFO nonblockingly. A strict first `bootstrap-ready` message now separates a bounded ten-second startup from the unchanged two-second ready, one-second result and one-second join budgets. All read-only/nonblocking flags, regular-file rejection, natural child exit zero for a PASS and cleanup checks remain required. Missing, malformed or failed bootstrap is a FAIL.

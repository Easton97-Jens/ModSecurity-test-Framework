# Framework Definition of Done Overlay

A Framework task is complete only when all applicable inherited completion criteria and these Framework-specific criteria are satisfied:

- the requested Framework outcome exists;
- Framework-owned files only were changed for a Framework-only task;
- relevant focused and repository-level validation was actually run or truthfully reported as not run/blocked;
- evidence claims match their layer and do not promote connector runtime without connector-owned proof;
- applicable English/German documentation and Framework Change Record requirements are satisfied;
- Framework status/diff were reviewed;
- Parent state was inspected separately when the task was Parent-coordinated;
- MRTS remained unchanged unless a separate user-selected MRTS task existed;
- task-owned processes/temporary resources were reconciled;
- Framework delivery state is reported exactly;
- Parent gitlink disposition is explicitly reported.

A complete Framework task does not imply Parent integration or connector capability promotion.
